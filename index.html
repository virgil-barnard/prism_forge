WebGPU prepares spectral wavetable banks and draws the live wavetable surfaces. Web Audio handles audio scheduling and synthesis. If WebGPU is unavailable, the studio uses CPU tables and a 2D visualizer. This is an original synth, with no Serum assets or preset compatibility.
